# Vibe Planner

Визуальный планировщик задач и времени, который помогает собрать дневной план, быстро переставлять карточки и экспортировать готовое расписание.

### Задачи и слоты

- Задачи это карточки с визуальными настройками, заметками и ссылкой.
- Слоты помогают быстро заполнять свободное время и по умолчанию ставятся на текущий день.

### Лайаут планнера

- Утренние часы по умолчанию скрыты.
- Прошедшие дни по умолчанию скрыты.
- Карточки можно наслаивать друг на друга (есть обратная настройка).
- При переносе карточки с зажатым `ALT` она копируется, а оригинал остается на месте.

### Экспорт JSON

- Экспортируются задачи как отдельный список.
- Экспортируется планнер с текущей раскладкой по дням и времени.
